# fasion

Fashion e-commerce demo with a Flask API and static product catalog pages.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Project structure

- `app.py` — Flask backend with product API
- `templates/` — Jinja templates
- `static/` — CSS, JS, and assets
- `*.html` — Standalone catalog pages
